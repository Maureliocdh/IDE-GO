===========================================
  AUTOCOMPLETADO (IntelliSense)
           SEMANA 5
===========================================

✅ IMPLEMENTADO: Sistema completo de autocompletado inteligente tipo IntelliSense

FUNCIONALIDADES:
================

1. ACTIVACIÓN AUTOMÁTICA
   - Se activa al escribir (mínimo 2 caracteres)
   - Analiza código en tiempo real
   - Filtra sugerencias según lo escrito
   - No interfiere con la escritura normal

2. ACTIVACIÓN MANUAL
   - Ctrl+Space: Muestra sugerencias en cualquier momento
   - Funciona incluso sin caracteres escritos
   - Útil para explorar opciones disponibles
   - Similar a VS Code, IntelliJ

3. VENTANA FLOTANTE
   - Aparece bajo el cursor
   - Diseño oscuro (#2d2d2d) integrado
   - Máximo 15 sugerencias visibles
   - Scroll automático si hay más
   - Sin bordes (overrideredirect)
   - Se oculta automáticamente cuando no es necesaria

4. SUGERENCIAS INTELIGENTES
   Incluye:
   a) Palabras clave de Go (43 palabras)
   b) Tipos de datos (int, string, bool, etc.)
   c) Funciones estándar (fmt.Println, len, append, etc.)
   d) Funciones definidas en el código actual
   e) Variables declaradas (var, :=)
   f) Constantes y tipos personalizados

5. NAVEGACIÓN CON TECLADO
   - ↑ Flecha Arriba: Sugerencia anterior
   - ↓ Flecha Abajo: Siguiente sugerencia
   - Enter: Completar con sugerencia seleccionada
   - Tab: Completar con sugerencia seleccionada
   - Escape: Ocultar autocompletado
   - Doble Click: Completar con item clickeado

6. FILTRADO INTELIGENTE
   - Búsqueda por prefijo (startswith)
   - Case-insensitive (no importa mayús/minús)
   - Actualización en tiempo real
   - Ordenación alfabética
   - Eliminación de duplicados

7. DETECCIÓN DE DEFINICIONES
   Extrae del código actual:
   - func nombre(...) → Detecta funciones
   - var nombre tipo → Detecta variables
   - nombre := valor → Detecta asignaciones cortas
   - Compatible con código parcial/incompleto

8. INTEGRACIÓN COMPLETA
   - Funciona en todas las tabs
   - No interfiere con otros atajos
   - Compatible con sistema de errores
   - No bloquea la UI
   - Se oculta al cambiar de tab o perder foco

FLUJO DE USO:
=============

CASO 1: Escritura Normal
1. Escribir: "fu"
2. Autocompletado aparece automáticamente
3. Sugerencias: func, funciones definidas
4. Seguir escribiendo o presionar ↓ para seleccionar
5. Enter para completar

CASO 2: Activación Manual
1. Posicionar cursor donde quieres autocompletar
2. Presionar Ctrl+Space
3. Ver todas las sugerencias disponibles
4. Navegar con flechas
5. Enter para completar

CASO 3: Completar Función Definida
1. Definir función: func calcular(a int) { ... }
2. Más abajo escribir: "cal"
3. Autocompletado muestra: calcular
4. Enter → completa automáticamente

CASO 4: Variables Locales
1. Declarar: resultado := 42
2. Más abajo escribir: "res"
3. Autocompletado muestra: resultado
4. Enter → completa automáticamente

CASO 5: Navegar Sugerencias
1. Escribir "f"
2. Aparecen: false, fallthrough, float32, float64, fmt.Println, for, func
3. Presionar ↓ varias veces para navegar
4. Enter en la opción deseada

COMPORTAMIENTO:
===============

MIENTRAS ESCRIBES:
→ Al llegar a 2 caracteres: Muestra autocompletado
→ Al seguir escribiendo: Filtra sugerencias
→ Si no hay coincidencias: Oculta autocompletado
→ Si hay coincidencias: Actualiza lista

AL PRESIONAR CTRL+SPACE:
→ Muestra todas las sugerencias disponibles
→ O filtra por lo ya escrito
→ Permite explorar opciones sin escribir

AL NAVEGAR CON FLECHAS:
→ ↑/↓: Cambia selección (circular)
→ Resalta opción actual en azul
→ Scroll automático para mantener visible

AL COMPLETAR (Enter/Tab):
→ Borra palabra parcial
→ Inserta sugerencia completa
→ Oculta ventana de autocompletado
→ Cursor queda al final de la palabra

AL PRESIONAR ESCAPE:
→ Oculta autocompletado inmediatamente
→ Palabra parcial permanece sin cambios
→ Continúa escritura normal

AL CAMBIAR DE TAB O PERDER FOCO:
→ Autocompletado se oculta automáticamente
→ No interfiere con otras operaciones

ARQUITECTURA TÉCNICA:
=====================

SimuladorGo:
Atributos:
- autocomplete_window: Toplevel flotante
- autocomplete_listbox: Listbox con sugerencias
- autocomplete_activo: bool (estado)
- palabra_actual: str (texto que se completa)
- sugerencias_actuales: list (sugerencias filtradas)
- palabras_clave: list (keywords de Go)

Métodos:
1. manejar_autocompletado(event) - Handler principal
2. mostrar_autocompletado() - Muestra ventana
3. crear_ventana_autocompletado() - Construye UI
4. ocultar_autocompletado() - Esconde ventana
5. navegar_autocompletado(direccion) - ↑↓
6. completar_palabra() - Inserta sugerencia
7. obtener_sugerencias() - Genera lista completa
8. activar_autocompletado_manual() - Ctrl+Space

Flujo de Eventos:
1. Usuario escribe en EditorTab
2. on_keyrelease() llama a manejar_autocompletado()
3. manejar_autocompletado() extrae palabra actual
4. Si >= 2 chars: llama a mostrar_autocompletado()
5. mostrar_autocompletado() obtiene y filtra sugerencias
6. Posiciona ventana bajo cursor
7. Usuario navega con flechas o completa con Enter
8. completar_palabra() inserta texto y oculta ventana

Bindings:
- <KeyRelease>: manejar_autocompletado()
- <Control-space>: activar_autocompletado_manual()
- <Escape>: ocultar_autocompletado()
- <Up> en autocomplete: navegar(-1)
- <Down> en autocomplete: navegar(1)
- <Return> en autocomplete: completar_palabra()
- <Tab> en autocomplete: completar_palabra()

Extracción de Definiciones (Regex):
- Funciones: r'\bfunc\s+(\w+)\s*\('
- Variables: r'\bvar\s+(\w+)'
- Asignaciones: r'\b(\w+)\s*:='
