===========================================
   DETECCIÓN DE ERRORES EN TIEMPO REAL
              SEMANA 3
===========================================

✅ IMPLEMENTADO: Sistema completo de detección y análisis de errores en tiempo real

FUNCIONALIDADES:
================

1. VALIDACIÓN EN TIEMPO REAL
   - Validación automática después de 750ms de inactividad
   - No interfiere con la escritura (delay inteligente)
   - Análisis en tres niveles:
     • Errores de indentación
     • Errores léxicos
     • Errores de sintaxis (parser)

2. PANEL DE ERRORES
   - Panel inferior desplegable (redimensionable)
   - Contador de errores en tiempo real
   - Lista completa de problemas encontrados
   - Indicador visual: "✓ Sin errores" en verde cuando todo está bien

3. VISUALIZACIÓN DE ERRORES
   - Subrayado rojo en líneas con errores
   - Fondo rojo oscuro (#3d1f1f) en líneas problemáticas
   - Marcadores permanecen mientras el error existe
   - Se actualizan automáticamente al corregir

4. INFORMACIÓN DETALLADA DE ERRORES
   Cada error muestra:
   - Tipo: Indentación / Léxico / Sintaxis / Parser
   - Número de línea exacta
   - Mensaje descriptivo del problema
   - Color codificado por tipo
   - Icono ✖ para identificación rápida

5. NAVEGACIÓN RÁPIDA
   - Click en cualquier error → Salta a la línea
   - Resaltado temporal amarillo de la línea (1.5s)
   - Scroll automático al error
   - Focus automático en el editor

6. INTEGRACIÓN CON TABS
   - Cada tab tiene su propia lista de errores
   - Al cambiar de tab, se muestra su lista de errores
   - Validación independiente por tab
   - Errores no interfieren entre tabs

TIPOS DE ERRORES DETECTADOS:
=============================

🟠 ERRORES DE INDENTACIÓN
   - Indentación inconsistente (tabs vs espacios)
   - Niveles de indentación incorrectos
   - Espacios/tabs mezclados

🔴 ERRORES LÉXICOS
   - Tokens no reconocidos
   - Caracteres inválidos
   - Literales mal formados
   - Strings sin cerrar

🔴 ERRORES DE SINTAXIS
   - Estructuras de control mal formadas
   - Paréntesis/llaves sin cerrar
   - Declaraciones incompletas
   - Operadores mal usados
   - Expected X, got Y

🔴 ERRORES DE PARSER
   - Estructura del programa inválida
   - Secuencia de tokens incorrecta
   - Expresiones mal formadas

COLORES POR TIPO:
================
- Indentación: Naranja (#ffa500)
- Léxico: Rojo claro (#ff6b6b)
- Sintaxis: Rojo salmón (#f48771)
- Parser: Rojo (#ff0000)

RENDIMIENTO:
============
- Delay de 750ms: Balance perfecto entre responsividad y CPU
- Validación cancelable: Si sigues escribiendo, cancela la anterior
- No bloquea la UI: Validación es rápida (<100ms típicamente)
- Memoria eficiente: Solo guarda errores actuales

COMPORTAMIENTO:
===============

MIENTRAS ESCRIBES:
→ Sin validación inmediata
→ Sin interrupciones
→ Escritura fluida

DESPUÉS DE 750ms SIN ESCRIBIR:
→ Validación automática
→ Actualización del panel
→ Marcadores en el editor
→ Contador actualizado

AL CORREGIR UN ERROR:
→ Validación automática
→ Error desaparece del panel
→ Marcadores se limpian
→ Contador se actualiza

AL HACER CLICK EN ERROR:
→ Cursor salta a la línea
→ Línea se resalta en amarillo
→ Editor recibe el foco
→ Scroll automático

CASOS DE USO:
=============

Ejemplo 1: Error de sintaxis
```go
func main() {
    x := 5
    if x > 3
        fmt.Println("mayor")  // ERROR: Falta {
    }
}
```
Panel mostrará: "Expected LBRACE, got IDENTIFIER [Línea 4]"

Ejemplo 2: Error de indentación
```go
func main() {
x := 5        // ERROR: No tiene indentación
    y := 10
}
```
Panel mostrará: "Indentación inconsistente [Línea 2]"

Ejemplo 3: Error léxico
```go
func main() {
    x := @5    // ERROR: @ no es válido
}
```
Panel mostrará: "Carácter no reconocido: @ [Línea 2]"

ARQUITECTURA TÉCNICA:
=====================

EditorTab:
- Atributo: self.errores (lista de diccionarios)
- Tags configurados: "error" (subrayado), "error_line" (fondo)

SimuladorGo:
- validation_timer: Timer para retrasar validación
- panel_errores: Frame inferior con lista de errores
- canvas_errores: Canvas con scroll para lista larga

Flujo de Validación:
1. EditorTab.on_keyrelease() → llama a validar_codigo_en_tiempo_real()
2. validar_codigo_en_tiempo_real() → cancela timer previo, programa nuevo (750ms)
3. ejecutar_validacion() → analiza código con IndentationChecker, Lexer, Parser
4. Captura excepciones y extrae información de errores
5. tab.errores se actualiza con lista de errores encontrados
6. marcar_errores_en_editor() → agrega tags visuales
7. actualizar_panel_errores() → reconstruye lista visual

Estructura de Error:
{
    'linea': 5,
    'tipo': 'Sintaxis',
    'mensaje': 'Expected RBRACE, got IDENTIFIER'
}
