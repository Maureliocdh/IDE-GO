===========================================
    EXPLORADOR DE ARCHIVOS (SIDEBAR)
              SEMANA 4
===========================================

✅ IMPLEMENTADO: Explorador de archivos completo con gestión de proyectos

FUNCIONALIDADES:
================

1. PANEL LATERAL IZQUIERDO
   - Sidebar redimensionable (mínimo 200px)
   - Diseño oscuro (#252526) integrado con el IDE
   - Header con título "📁 EXPLORADOR"
   - Botones de acción rápida en header

2. ÁRBOL DE ARCHIVOS (TREEVIEW)
   - Visualización jerárquica de carpetas y archivos
   - Carpetas expandibles/colapsables
   - Navegación completa por estructura del proyecto
   - Scroll horizontal y vertical
   - Ordenación alfabética (carpetas primero, luego archivos)
   - Selección con resaltado azul (#094771)

3. ICONOS POR TIPO DE ARCHIVO
   Iconos visuales según extensión:
   - 🟦 .go (archivos Go)
   - 🐍 .py (Python)
   - 📜 .js (JavaScript)
   - 📘 .ts (TypeScript)
   - 🌐 .html (HTML)
   - 🎨 .css (CSS)
   - 📋 .json (JSON)
   - 📝 .md (Markdown)
   - 📄 .txt (Texto plano)
   - ⚙️ .c/.cpp (C/C++)
   - 📌 .h (Headers)
   - 🔧 .asm (Ensamblador)
   - 📁 Carpetas
   - 📄 Otros archivos

4. ABRIR CARPETA DE PROYECTO
   Tres formas de abrir:
   - Menú: Archivo → Abrir Carpeta...
   - Botón 📂 en header del explorador
   - Atajo: (futuro Ctrl+K Ctrl+O)
   
   Al abrir carpeta:
   - Carga estructura completa del proyecto
   - Ignora carpetas ocultas (.git, __pycache__, node_modules)
   - Carga recursivamente todas las subcarpetas
   - Expande automáticamente la carpeta raíz

5. ABRIR ARCHIVOS
   - Doble click en archivo → Abre en nueva tab
   - Si ya está abierto → Selecciona su tab existente
   - Detecta archivos duplicados para evitar tabs repetidas
   - Soporta múltiples archivos abiertos simultáneamente
   - Mantiene consistencia con sistema de tabs

6. MENÚ CONTEXTUAL (CLICK DERECHO)
   Opciones disponibles:
   
   📄 Nuevo Archivo
   - Crea archivo en carpeta seleccionada
   - Pide nombre por diálogo
   - Refresca automáticamente el árbol
   
   📁 Nueva Carpeta
   - Crea subcarpeta en carpeta seleccionada
   - Pide nombre por diálogo
   - Refresca automáticamente el árbol
   
   ✏️ Renombrar
   - Renombra archivo o carpeta seleccionada
   - Muestra nombre actual como valor inicial
   - Actualiza automáticamente el árbol
   
   🗑️ Eliminar
   - Elimina archivo o carpeta
   - Confirmación antes de eliminar
   - Para carpetas: elimina todo el contenido recursivamente
   
   🔄 Refrescar
   - Refresca el árbol de archivos
   - Útil si cambios externos al IDE

7. GESTIÓN INTELIGENTE
   - Filtrado automático de carpetas ocultas
   - Ignora __pycache__, .git, node_modules
   - Manejo de errores de permisos
   - Prevención de errores al manipular archivos
   - Validación de operaciones antes de ejecutar

8. INTEGRACIÓN COMPLETA
   - Sincronizado con sistema de tabs
   - Detección de archivos ya abiertos
   - Paths absolutos para evitar ambigüedades
   - Codificación UTF-8 por defecto
   - Compatible con Windows, Linux, macOS

FLUJO DE TRABAJO:
=================

PASO 1: Abrir Proyecto
→ Click en 📂 o Menú → Archivo → Abrir Carpeta
→ Seleccionar carpeta del proyecto
→ Árbol se carga automáticamente

PASO 2: Navegar por Archivos
→ Click en carpetas para expandir/colapsar
→ Ver estructura completa del proyecto
→ Scroll para proyectos grandes

PASO 3: Abrir Archivos
→ Doble click en archivo
→ Se abre en nueva tab en el editor
→ Si ya estaba abierto, selecciona su tab

PASO 4: Gestionar Archivos
→ Click derecho en archivo/carpeta
→ Seleccionar opción del menú
→ Crear, renombrar o eliminar
→ Árbol se actualiza automáticamente

PASO 5: Trabajar con Múltiples Archivos
→ Abrir varios archivos desde el explorador
→ Cambiar entre tabs con Ctrl+Tab
→ Editar y guardar independientemente
→ Árbol muestra siempre la estructura actual

CASOS DE USO:
=============

Ejemplo 1: Crear Nuevo Archivo
1. Click derecho en carpeta "src"
2. Seleccionar "📄 Nuevo Archivo"
3. Escribir nombre: "config.go"
4. Enter → Archivo creado
5. Árbol se actualiza mostrando "config.go"

Ejemplo 2: Renombrar Archivo
1. Click derecho en "utils.go"
2. Seleccionar "✏️ Renombrar"
3. Cambiar a: "helpers.go"
4. Enter → Archivo renombrado
5. Si estaba abierto, la tab actualiza su nombre

Ejemplo 3: Eliminar Carpeta
1. Click derecho en carpeta "temp"
2. Seleccionar "🗑️ Eliminar"
3. Confirmar: "¿Eliminar carpeta 'temp' y su contenido?"
4. Sí → Carpeta eliminada recursivamente
5. Árbol se actualiza

Ejemplo 4: Navegar Proyecto Grande
1. Abrir carpeta con muchos archivos
2. Usar scroll vertical para navegar
3. Expandir solo las carpetas necesarias
4. Doble click en archivo específico
5. Archivo se abre en el editor

COMPORTAMIENTO:
===============

AL ABRIR CARPETA:
→ Árbol se limpia completamente
→ Se carga estructura recursivamente
→ Carpetas se ordenan alfabéticamente
→ Archivos se ordenan alfabéticamente
→ Carpeta raíz se expande automáticamente
→ Ignorados: .git, __pycache__, node_modules, archivos ocultos

AL DOBLE CLICK EN ARCHIVO:
→ Verifica si ya está abierto en alguna tab
→ Si está abierto: Selecciona esa tab
→ Si no está abierto: Crea nueva tab
→ Lee contenido con encoding UTF-8
→ Aplica resaltado de sintaxis automáticamente
→ Marca como no modificado inicialmente

AL CREAR ARCHIVO/CARPETA:
→ Muestra diálogo para ingresar nombre
→ Valida que no esté vacío
→ Crea en la carpeta seleccionada
→ Si se seleccionó archivo, usa su carpeta padre
→ Refresca árbol para mostrar item nuevo
→ Muestra mensaje de confirmación

AL ELIMINAR:
→ Muestra confirmación antes de eliminar
→ Diferencia entre archivo y carpeta
→ Para carpetas: advierte sobre contenido
→ Ejecuta eliminación recursiva si necesario
→ Refresca árbol
→ Maneja errores (permisos, archivo en uso)

AL RENOMBRAR:
→ Muestra diálogo con nombre actual
→ Permite editar nombre
→ Valida que no sea igual al actual
→ Ejecuta rename en sistema de archivos
→ Refresca árbol
→ Actualiza tabs si archivo estaba abierto

ARQUITECTURA TÉCNICA:
=====================

SimuladorGo:
- Atributo: self.carpeta_proyecto (ruta actual del proyecto)
- Atributo: self.panel_explorador (Frame del sidebar)
- Atributo: self.tree_archivos (ttk.Treeview)

Estructura del Layout:
paned_window (HORIZONTAL)
├─ panel_explorador (250px, redimensionable)
│  ├─ header_explorador (40px fijo)
│  │  ├─ Label: "📁 EXPLORADOR"
│  │  ├─ Button: 🔄 (refrescar)
│  │  └─ Button: 📂 (abrir carpeta)
│  └─ tree_archivos (Treeview con scrollbars)
├─ frame_editor (centro, 400px mínimo)
│  └─ editor_paned (VERTICAL)
│     ├─ editor_notebook (tabs)
│     └─ panel_errores
└─ frame_derecho (derecha, 400px mínimo)
   └─ notebook (output tabs)

Treeview Node Structure:
- text: "📁 nombre_carpeta" o "🟦 archivo.go"
- values: (ruta_absoluta,)
- tags: "info" para mensajes, ninguno para items

Métodos Implementados:
1. crear_explorador_archivos() - Construye UI
2. abrir_carpeta_proyecto() - Diálogo para seleccionar carpeta
3. cargar_estructura_carpeta() - Carga árbol completo
4. agregar_nodos_recursivo() - Construcción recursiva del árbol
5. obtener_icono_archivo() - Retorna emoji según extensión
6. on_tree_double_click() - Handler doble click
7. abrir_archivo_desde_explorador() - Abre en tab
8. on_tree_right_click() - Menú contextual
9. crear_archivo() - Crea nuevo archivo
10. crear_carpeta() - Crea nueva carpeta
11. eliminar_item() - Elimina archivo/carpeta
12. renombrar_item() - Renombra archivo/carpeta
13. refrescar_explorador() - Recarga árbol

Bindings:
- <Double-Button-1>: on_tree_double_click
- <Button-3>: on_tree_right_click (menú contextual)
