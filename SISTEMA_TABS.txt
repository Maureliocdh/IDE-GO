===========================================
   SISTEMA DE TABS MÚLTIPLES - SEMANA 2
===========================================

✅ IMPLEMENTADO: Sistema completo de pestañas múltiples para editor

FUNCIONALIDADES:
================

1. GESTIÓN DE TABS
   - Editor multi-archivo: Trabaja con múltiples archivos simultáneamente
   - Cada tab independiente: Tiene su propio contenido, estado (modificado/no modificado), y ruta
   - Tab inicial: Al iniciar, se crea automáticamente una tab vacía "Sin título"

2. ATAJOS DE TECLADO
   - Ctrl+W: Cerrar tab actual (con confirmación si hay cambios sin guardar)
   - Ctrl+Tab: Siguiente tab
   - Ctrl+Shift+Tab: Tab anterior
   - Ctrl+N: Nuevo archivo (crea nueva tab)

3. INDICADORES VISUALES
   - Nombre del archivo en la tab
   - Símbolo "•" cuando hay cambios sin guardar
   - Tab activa resaltada visualmente

4. OPERACIONES DE ARCHIVO
   - Abrir archivo: Abre en nueva tab (o reutiliza tab vacía actual)
   - Guardar: Guarda el archivo de la tab actual
   - Guardar Como: Guarda la tab actual con nuevo nombre
   - Nuevo: Crea nueva tab vacía
   - Cerrar aplicación: Verifica TODAS las tabs con cambios sin guardar

5. EDICIÓN POR TAB
   Todas las funcionalidades funcionan en la tab actual:
   - Resaltado de sintaxis
   - Auto-indentación
   - Zoom (Ctrl+MouseWheel)
   - Búsqueda y reemplazo (Ctrl+F)
   - Ir a línea (Ctrl+G)
   - Duplicar línea (Ctrl+D)
   - Comentar/Descomentar (Ctrl+/)
   - Números de línea actualizados automáticamente

6. BARRA DE ESTADO
   La barra de estado siempre muestra la información de la tab actual:
   - Posición del cursor (línea, columna)
   - Total de líneas
   - Codificación (UTF-8)
   - Tipo de archivo (Go)
   - Nivel de zoom

7. COMPILACIÓN Y EJECUCIÓN
   - Siempre usa el código de la tab actual
   - Puedes mantener diferentes versiones en tabs distintas
   - Cambia de tab y ejecuta sin guardar para probar diferentes versiones

ARQUITECTURA TÉCNICA:
====================

EditorTab:
- Encapsula: frame, texto_codigo (CustomText), linenumbers, scrollbar
- Estado propio: ruta_actual, archivo_modificado, font_size
- Nombre automático: "Sin título", "Sin título 2", etc. o nombre del archivo

ttk.Notebook:
- Contiene todas las tabs (editor_notebook)
- Gestión automática de selección visual
- Evento on_tab_changed se dispara al cambiar de tab

Métodos *_tab:
- resaltar_sintaxis_tab(tab, event)
- aplicar_regex_tab(tab, pattern, tag)
- actualizar_barra_estado_tab(tab, event)
- auto_indentacion_tab(tab)
- zoom_editor_tab(tab, event)

NOTAS:
======
- Cada tab es completamente independiente
- El zoom es por tab (cada tab puede tener diferente zoom)
- Los cambios sin guardar se rastrean por tab
- Al cerrar la aplicación, se verifica cada tab con cambios
