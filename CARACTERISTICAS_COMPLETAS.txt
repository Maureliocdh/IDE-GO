┌─────────────────────────────────────────────────────────────────────────────┐
│ 1. SISTEMA MULTI-TAB                                                        │
└─────────────────────────────────────────────────────────────────────────────┘
✓ Múltiples pestañas independientes con EditorTab class
✓ Cada pestaña mantiene su propio estado (archivo, modificación, errores)
✓ Crear nueva pestaña: Ctrl+N o botón "Nueva Tab"
✓ Cerrar pestaña: Ctrl+W o botón X en la pestaña
✓ Navegar pestañas: Ctrl+Tab (siguiente), Ctrl+Shift+Tab (anterior)
✓ Indicador de archivos no guardados (*) en el título
✓ Confirmación al cerrar pestañas modificadas

┌─────────────────────────────────────────────────────────────────────────────┐
│ 2. EDITOR DE CÓDIGO AVANZADO                                                │
└─────────────────────────────────────────────────────────────────────────────┘
✓ Números de línea dinámicos
✓ Resaltado de sintaxis para Go:
  - Palabras clave (azul)
  - Tipos de datos (verde)
  - Strings (rojo)
  - Números (verde claro)
  - Comentarios (verde oscuro)
  - Operadores y símbolos
✓ Auto-indentación al presionar Enter
✓ Zoom con Ctrl+Rueda del mouse (8-30pt)
✓ Resetear zoom: Ctrl+0
✓ Soporte Unicode completo

┌─────────────────────────────────────────────────────────────────────────────┐

└─────────────────────────────────────────────────────────────────────────────┘
✓ Validación automática con delay de 750ms
✓ Panel de errores dedicado con lista de problemas
✓ Detección de errores:
  - Indentación incorrecta
  - Errores léxicos
  - Errores de sintaxis

✓ Marcado visual en el editor:
  - Subrayado rojo en líneas con error
  - Fondo rojo semitransparente
✓ Click en el panel de errores para navegar al error
✓ Contador de errores en tiempo real

┌─────────────────────────────────────────────────────────────────────────────┐

└─────────────────────────────────────────────────────────────────────────────┘
✓ TreeView con estructura de carpetas
✓ Botón 📂 para abrir carpeta de proyecto
✓ Doble click para abrir archivos
✓ Menú contextual (click derecho):
  - Crear nuevo archivo
  - Eliminar archivo/carpeta
  - Renombrar archivo/carpeta
✓ Iconos por tipo de archivo:
  - 📄 Archivos .go
  - 📝 Otros archivos
  - 📁 Carpetas
✓ Filtrado de carpetas ocultas (__pycache__, .git, node_modules)

┌─────────────────────────────────────────────────────────────────────────────┐
│ 5. AUTOCOMPLETADO INTELIGENTE                                               │
└─────────────────────────────────────────────────────────────────────────────┘
✓ Activación automática al escribir 2+ caracteres
✓ Activación manual: Ctrl+Space
✓ Ventana flotante con hasta 15 sugerencias
✓ Sugerencias incluyen:
  - 43 palabras clave de Go
  - Funciones definidas en el código

✓ Completar: Enter o Tab

│ 6. GO TO DEFINITION (F12)                                                   │
└─────────────────────────────────────────────────────────────────────────────┘
✓ Presiona F12 sobre un símbolo para ir a su definición
✓ Encuentra:
  - Definiciones de funciones (func nombre)
  - Declaraciones de variables (var nombre, nombre :=)
  - Constantes (const nombre)
  - Tipos personalizados (type nombre)
✓ Resaltado temporal de la línea de definición (1 segundo)
✓ Historial de navegación para volver atrás
✓ Mensaje si no se encuentra la definición

┌─────────────────────────────────────────────────────────────────────────────┐
│ 7. REFACTORING: RENAME SYMBOL (F2)                                          │
└─────────────────────────────────────────────────────────────────────────────┘
✓ Presiona F2 sobre un símbolo para renombrarlo
✓ Busca y reemplaza TODAS las ocurrencias en el archivo
✓ Solo reemplaza palabras completas (no subcadenas)
✓ Protección contra renombrar palabras clave
✓ Validación de nombre nuevo (debe ser identificador válido)
✓ Muestra contador de ocurrencias antes de confirmar
✓ Confirmación antes de aplicar cambios
✓ Mensaje de éxito con cantidad de cambios realizados

┌─────────────────────────────────────────────────────────────────────────────┐
│ 8. SISTEMA DE SNIPPETS                                                      │
└─────────────────────────────────────────────────────────────────────────────┘
Escribe el nombre del snippet y presiona Tab para expandir:

✓ main    → func main() { }
✓ func    → func nombre() { }
✓ for     → for i := 0; i < 10; i++ { }
✓ fori    → for i := 0; i < len(arr); i++ { }
✓ forr    → for _, v := range collection { }
✓ if      → if condition { }
✓ ife     → if condition { } else { }
✓ sw      → switch expr { case value1: case value2: default: }
✓ struct  → type Name struct { }
✓ interface → type Name interface { }
✓ var     → var name type
✓ const   → const name = value
✓ fmt     → fmt.Println()
✓ err     → if err != nil { return err }
✓ errlog  → if err != nil { log.Fatal(err) }

Expansión automática con posicionamiento inteligente del cursor

📝 NOTAS DE USO
═══════════════════════════════════════════════════════════════════════════════

1. PRIMER USO:
   - Ejecuta: python main.py
   - Se abre con una pestaña vacía lista para escribir código

2. ABRIR PROYECTO:
   - Click en el botón 📂 "Abrir Carpeta"
   - Selecciona la carpeta de tu proyecto
   - El explorador mostrará todos los archivos .go

3. ESCRIBIR CÓDIGO:
   - Escribe código Go en el editor
   - El resaltado de sintaxis se aplica automáticamente
   - Los errores se detectan mientras escribes

4. AUTOCOMPLETADO:
   - Comienza a escribir y aparecerán sugerencias
   - O presiona Ctrl+Space para activar manualmente
   - Usa ↑↓ para navegar y Enter/Tab para completar

5. SNIPPETS:
   - Escribe "main" y presiona Tab → crea función main()
   - Escribe "for" y presiona Tab → crea bucle for
   - Y muchos más...

6. IR A DEFINICIÓN:
   - Posiciona el cursor sobre una función o variable
   - Presiona F12 para ir a su definición

7. RENOMBRAR:
   - Posiciona el cursor sobre un símbolo
   - Presiona F2, ingresa el nuevo nombre y confirma
   - Todas las ocurrencias se renombran automáticamente

8. TERMINAL:
   - Presiona F8 para mostrar/ocultar el terminal
   - Escribe comandos y presiona Enter
   - Útil para git, npm, python, etc.

9. EJECUTAR:
   - F5: Ejecuta tu código Go y ve el resultado
   - F6: Compila a C y ve el código generado
   - F7: Genera ensamblador
   - Todas las salidas aparecen en pestañas separadas

10. ESTADÍSTICAS:
    - Menú Herramientas → Estadísticas
    - Ve métricas detalladas de tu código
