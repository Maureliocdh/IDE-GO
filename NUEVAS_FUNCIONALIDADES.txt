📊 1. BARRA DE ESTADO (Parte inferior de la ventana)
═══════════════════════════════════════════════════════════════════════════════════════

✓ Muestra tu posición actual: "Ln 45, Col 12"
✓ Total de líneas del archivo: "Total: 156 líneas"
✓ Codificación: "UTF-8"
✓ Tipo de archivo: "Go"
✓ Nivel de zoom actual: "100%"

🔹 Actualización automática: La barra se actualiza en tiempo real mientras escribes o 
   mueves el cursor.

═══════════════════════════════════════════════════════════════════════════════════════
⭐ 2. INDICADOR DE CAMBIOS SIN GUARDAR
═══════════════════════════════════════════════════════════════════════════════════════

✓ El título de la ventana muestra un asterisco (*) cuando hay cambios sin guardar
✓ Ejemplo: "Go-APK-IDE - main.go *"
✓ El asterisco desaparece automáticamente al guardar (Ctrl+S)

═══════════════════════════════════════════════════════════════════════════════════════
⚠️ 3. CONFIRMACIÓN AL CERRAR/NUEVO ARCHIVO
═══════════════════════════════════════════════════════════════════════════════════════

✓ Si intentas cerrar el IDE o crear un nuevo archivo con cambios sin guardar,
  aparecerá un diálogo preguntando: "¿Desea guardar los cambios?"
  
  Opciones:
  • Sí → Guarda los cambios y continúa
  • No → Descarta los cambios y continúa
  • Cancelar → Vuelve al editor sin hacer nada

═══════════════════════════════════════════════════════════════════════════════════════
🎯 4. IR A LÍNEA (Ctrl+G)
═══════════════════════════════════════════════════════════════════════════════════════

Cómo usar:
1. Presiona Ctrl+G
2. Escribe el número de línea (ej: 45)
3. Presiona Enter

✓ El cursor salta a esa línea automáticamente
✓ La línea se resalta en azul durante 1 segundo para que la encuentres fácilmente
✓ Perfecto para depurar errores cuando el compilador te dice "Error en línea 128"

═══════════════════════════════════════════════════════════════════════════════════════
📋 5. DUPLICAR LÍNEA (Ctrl+D)
═══════════════════════════════════════════════════════════════════════════════════════

Cómo usar:
• Sin selección: Presiona Ctrl+D → Duplica la línea actual debajo
• Con selección: Selecciona texto y presiona Ctrl+D → Duplica el texto seleccionado

Ejemplo:
  Antes:
    x := 10
    ▮ (cursor aquí)
    
  Después de Ctrl+D:
    x := 10
    x := 10
    ▮

✓ Útil para crear código repetitivo rápidamente
✓ Funciona con múltiples líneas seleccionadas

═══════════════════════════════════════════════════════════════════════════════════════
💬 6. COMENTAR/DESCOMENTAR (Ctrl+/)
═══════════════════════════════════════════════════════════════════════════════════════

Cómo usar:
• Coloca el cursor en una línea (o selecciona múltiples líneas)
• Presiona Ctrl+/

Si la línea NO está comentada:
  Antes:  x := 10
  Después: // x := 10

Si la línea YA está comentada:
  Antes:  // x := 10
  Después: x := 10

✓ Funciona con múltiples líneas seleccionadas a la vez
✓ Respeta la indentación automáticamente
✓ Inteligente: detecta si las líneas están comentadas o no

═══════════════════════════════════════════════════════════════════════════════════════
🔍 7. ZOOM DINÁMICO (Ctrl + Rueda del ratón)
═══════════════════════════════════════════════════════════════════════════════════════

Cómo usar:
• Mantén presionada la tecla Ctrl
• Gira la rueda del ratón hacia arriba → Aumentar zoom (letra más grande)
• Gira la rueda del ratón hacia abajo → Disminuir zoom (letra más pequeña)

✓ Rango: 8pt (mínimo) hasta 30pt (máximo)
✓ El porcentaje de zoom se muestra en la barra de estado (esquina inferior derecha)
✓ Zoom por defecto: 100% (13pt)

Ejemplo de uso:
  - Presentar código en un proyector → Zoom al 200%
  - Ver más código en pantalla → Zoom al 80%
  - Leer código con dificultad visual → Zoom al 150%

💡 CONSEJOS DE USO
═══════════════════════════════════════════════════════════════════════════════════════

1. Workflow recomendado:
   - Escribe código
   - El asterisco (*) aparece en el título
   - Presiona Ctrl+S para guardar
   - El asterisco desaparece

2. Para debugging rápido:
   - El compilador dice "Error en línea 45"
   - Presiona Ctrl+G
   - Escribe "45" y Enter
   - ¡Listo! Estás en la línea del error

3. Para código repetitivo:
   - Escribe la primera línea
   - Presiona Ctrl+D varias veces
   - Edita las diferencias en cada línea

4. Para comentar bloques grandes:
   - Selecciona todas las líneas (arrastra o Shift+Flechas)
   - Presiona Ctrl+/
   - ¡Todas las líneas se comentan a la vez!

5. Para presentaciones:
   - Ctrl+Rueda hacia arriba para aumentar el texto
   - El público puede ver el código claramente
