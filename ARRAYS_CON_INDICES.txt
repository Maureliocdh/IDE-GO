En Go, puedes especificar el índice de elementos específicos en la inicialización
de arrays. Los elementos intermedios se rellenan automáticamente con valores cero.

EJEMPLOS:

1. Índices específicos con inferencia de tamaño:
   ✓ a := [...]int{100, 3: 400, 500}
   
   Resultado: [100, 0, 0, 400, 500]
   - Índice 0: 100 (secuencial)
   - Índice 1: 0 (relleno automático)
   - Índice 2: 0 (relleno automático)
   - Índice 3: 400 (especificado)
   - Índice 4: 500 (secuencial después de índice especificado)

2. Múltiples índices específicos:
   ✓ b := [...]int{0: 10, 2: 20, 4: 40, 6: 60}
   
   Resultado: [10, 0, 20, 0, 40, 0, 60]
   - Todos los índices pares especificados
   - Índices impares rellenados con 0

3. Mezcla de secuencial e indexado:
   ✓ c := [...]int{1, 2, 5: 50, 60, 70}
   
   Resultado: [1, 2, 0, 0, 0, 50, 60, 70]
   - Índices 0-1: secuencial (1, 2)
   - Índices 2-4: relleno automático (0, 0, 0)
   - Índice 5: especificado (50)
   - Índices 6-7: secuencial después del 5 (60, 70)

4. Con tamaño explícito:
   ✓ d := [10]int{1: 11, 5: 55, 9: 99}
   
   Resultado: [0, 11, 0, 0, 0, 55, 0, 0, 0, 99]
   - Solo los índices 1, 5 y 9 especificados
   - Resto relleno con 0

5. Solo índices (sin valores secuenciales):
   ✓ e := [...]int{5: 500, 10: 1000}
   
   Resultado: [0, 0, 0, 0, 0, 500, 0, 0, 0, 0, 1000]

El parser ahora:
1. Detecta el patrón `expresión : valor`
2. Interpreta la expresión como índice (debe ser IntegerLiteral)
3. Rellena automáticamente con IntegerLiteral(0) los índices intermedios
4. Continúa con el siguiente elemento de forma secuencial

ALGORITMO:

```python
def parse_array_elements_with_indices():
    elements = []
    current_index = 0
    
    while not at end:
        expr = parse_expression()
        
        if next_token is COLON:
            # expr es el índice, no el valor
            target_index = expr.value
            
            # Rellenar huecos con 0
            while current_index < target_index:
                elements.append(IntegerLiteral(0))
                current_index++
            
            # Parsear el valor real
            value = parse_expression()
            elements.append(value)
            current_index++
        else:
            # Elemento secuencial normal
            elements.append(expr)
            current_index++
    
    return elements
```

═══════════════════════════════════════════════════════════════════════════════
⚠️  LIMITACIONES Y CONSIDERACIONES
═══════════════════════════════════════════════════════════════════════════════

1. ÍNDICES DEBEN SER LITERALES ENTEROS:
   ✓ a := [...]int{3: 300}           // OK
   ❌ a := [...]int{x: 300}           // NO: x es variable
   ❌ a := [...]int{(1+2): 300}       // NO: expresión
   
   El índice debe ser un IntegerLiteral en tiempo de compilación.

2. ÍNDICES DEBEN SER NO NEGATIVOS:
   ✓ a := [...]int{0: 100, 5: 500}   // OK
   ❌ a := [...]int{-1: 100}          // NO: índice negativo

3. ORDEN DE ÍNDICES:
   Los índices NO necesitan estar en orden ascendente:
   ✓ a := [...]int{5: 50, 2: 20, 8: 80}  // OK
   
   El parser los procesa en orden de aparición y rellena huecos.

4. VALORES CERO:
   Los elementos no especificados se rellenan con el valor cero del tipo:
   - int: 0
   - string: ""
   - bool: false
   - float: 0.0
   - pointer: nil
   - struct: todos los campos con valor cero
